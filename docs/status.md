# 项目状态

## 已完成

- Ubuntu 24.04、ROS 2 Jazzy、Gazebo Harmonic、PX4 SITL 环境联调
- 自定义 Gazebo 世界、云台相机和目标模型
- Gazebo 图像及仿真时钟桥接到 ROS 2
- 图像最新帧限流，降低 CPU 推理时的消息堆积
- YOLOv8 ROS 2 推理节点
- 检测框、FPS、延迟和运行状态 HUD
- 终端仪表盘、逐帧 JSONL 与滚动统计 JSON
- 随机目标生成、随机航点任务和数据采集节点
- 内存、Swap、日志写盘和 GPU 驱动稳定性排查
- 在当前虚拟机资源下完成约 10 分钟连续运行验证

## 部分完成

- 仿真数据采集代码已经存在，但尚未形成经过完整验证、可公开复现的数据集版本。
- Windows 训练脚本和 Ubuntu 推理脚本已经分离，但自训练权重尚未作为正式实验结果发布。
- 稳定性问题已经缓解，但仍缺少长时间运行数据和统一 benchmark。

## 尚未完成

- 标准化的数据集划分、训练结果和精度评估
- 检测目标跟踪
- ROS 2 检测结果驱动的闭环飞行控制
- 真实无人机部署与实飞测试
- 面向不同硬件环境的完整自动安装

## 下一阶段建议

1. 固定一套仿真场景、随机种子和采集参数。
2. 发布一个小型示例数据集及对应训练配置。
3. 记录 FPS、平均延迟、P95 延迟、内存峰值和连续运行时长。
4. 增加演示截图和短视频。
5. 在感知链路稳定后再增加跟踪或闭环控制。
